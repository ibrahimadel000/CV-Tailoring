# تحديث 07 — توزيع ذكي وتحكم في فواصل الصفحات

تحديث داخل مشروعك الحالي، وليس مشروعاً مستقلاً. يتطلب Batch 06 المثبّت بنجاح.

## ما تغيّر
- القياس يستخدم الخطوط والعرض الحقيقيين من محرك PDF، وليس عدد الحروف. تجري مرحلة قياس ثم مرحلة إخراج؛ المعاينة والتصدير يستخدمان الناتج النهائي المشترك نفسه.
- الوضع Automatic يجمع الوظائف المعتادة القصيرة في صفحة واحدة إن أمكن، وينقلها إلى الصفحة التالية عند الحاجة. الوظائف الطويلة تتدفق لتجنب فراغات كبيرة.
- القاعدة التقنية الافتراضية تجمع العنصر الذي لا يتجاوز 60% من مساحة صفحة A4 القابلة للاستخدام. خيار Keep together يسمح بالاحتفاظ بعنصر أطول، ما دام يتسع لصفحة كاملة.
- عنوان القسم يبقى مع بداية أول عنصر؛ عنوان الوظيفة والجهة وأول نقطة يبقون معاً عندما تتسع هذه البداية لصفحة. النصوص أو النقاط الأطول من صفحة تُقسم بأمان دون فرض عنصر غير قابل للتقسيم أكبر من الصفحة.
- النقاط المعتادة لا تُقسم بين الصفحات إذا كانت تتسع لصفحة واحدة. النقطة الضخمة التي تتجاوز صفحة كاملة تبقى قابلة للتدفق كي لا يُقصّ محتواها.
- لا نحاول إبقاء قسم Experience بأكمله في صفحة واحدة؛ يمكن أن يمتد على عدة صفحات بصورة طبيعية.

## أين الخيارات؟
1. افتح Work experience، ثم Edit للوظيفة.
2. أسفل نقاط الإنجازات افتح Page layout.
3. اختر Automatic أو Keep this entry together أو Start on a new page.
4. يمكن الرجوع إلى Automatic من القائمة أو زر Reset to Automatic / Remove manual page break. تبقى الأدوات مفتوحة أثناء إعادة الضبط لتجنب قفز النموذج.
5. عند فتح أي قسم غير Personal details، يوجد Page layout للقسم نفسه مع خيار بدء القسم بصفحة جديدة.
6. أقسام Experience المخصصة مثل Courses وVolunteering تملك خيارات العناصر نفسها.

تظهر ملاحظة Manual page break أو Keep together في ملخص العنصر، وملاحظة فاصل القسم في عنوانه المطوي. هذه ملاحظات للمحرر ولا تُطبع في PDF.

## تحكم دون مفاجآت
- Keep together أو فاصل يدوي قد يترك مساحة فارغة في الورقة السابقة ويزيد عدد الصفحات. لا نُصغّر الخط ولا نحذف النص تلقائياً لفرض صفحتين.
- العنصر الأطول من صفحة كاملة يظل قابلاً للتقسيم حتى عند اختيار Keep together؛ هذا مقصود لحماية المحتوى.
- إعدادات العنصر مرتبطة بمعرّفه، فتتبعه عند إعادة الترتيب، لا الوظيفة التي تحتل مكانه القديم.
- الفاصل على قسم فارغ لا ينشئ صفحة فارغة. فاصل القسم وفاصل أول عنصر لا يضيفان فاصلين متتاليين.
- الاختيارات تحفظ تلقائياً مع السيرة، وضمن JSON backup، ومع الاستيراد والنسخ. السير القديمة التي لا تحتوي pageLayout تستخدم Automatic دون ترحيل أو حذف بيانات.
- أدوات الأقسام المقفلة تحترم القفل. لا تغيير للنص أو المحتوى لمجرد تعديل تخطيط الصفحات.

## التثبيت الآمن
1. نزّل Download JSON backup من قائمة ⋯ أولاً.
2. أوقف خادم التطوير بـ Ctrl+C.
3. ضع CV-Builder-Page-Control-Batch-07.zip داخل E:\cv tailor - Copy دون فكّه يدوياً.
4. الصق الكود في PowerShell:

```powershell
$ErrorActionPreference = "Stop"
$project = "E:\cv tailor - Copy"
$zip = Join-Path $project "CV-Builder-Page-Control-Batch-07.zip"
if (-not (Test-Path -LiteralPath $zip -PathType Leaf)) { throw "ZIP not found in the project folder." }
Set-Location -LiteralPath $project
$folder = Join-Path $project ("_cv-page-control-batch07-" + [guid]::NewGuid().ToString("N"))
Expand-Archive -LiteralPath $zip -DestinationPath $folder
& powershell.exe -NoProfile -ExecutionPolicy Bypass -File (Join-Path $folder "Apply-UI.ps1") -ProjectPath $project
if ($LASTEXITCODE -ne 0) { throw "Update stopped. Send the error; do not overwrite files manually." }
npm run build
if ($LASTEXITCODE -ne 0) { throw "Build failed. Send the error." }
npm run dev
```

المتوقع Applied 10 files successfully (أو أقل إذا كانت ملفات مطبّقة سابقاً).
إذا توقف بسبب Local changes detected أو اختلاف package.json، أرسل الخطأ ولا تفرض الاستبدال. لا يلزم npm install.
استخدم نفس المتصفح وعنوان التشغيل/المنفذ القديم للوصول إلى السير المحفوظة.

## الحماية والتراجع
تسعة ملفات معدلة وملف جديد PageLayoutControls.tsx. لا تغيير في package.json أو lockfile أو .env أو خدمة AI أو ملف المخزن. إضافة اختيارية pageLayout في شكل CVProfile وفي التحقق من JSON. لا يتم حذف السير أو تحويل محتواها.
المثبّت يتحقق من جميع البصمات قبل الكتابة ويحفظ الأصل داخل .cv-builder-backups ويطبع المسار. للتراجع استخدم Rollback-UI.ps1 داخل النسخة الاحتياطية مع -BackupPath؛ يتوقف إذا تغيرت الملفات لاحقاً. احتفظ بنسخة JSON الجديدة؛ الإصدار الأقدم لا يعرف خيارات التخطيط الجديدة وقد يتجاهلها عند الاستيراد.

## حدود هذه الدفعة
الخطوط في PDF ما زالت Latin فقط. العربية تبقى محفوظة وتظهر في المعاينة المستمرة مع تحذير Unpaginated، دون ادعاء عدد صفحات دقيق أو دعم تصدير العربية. لا تغيير في الهوامش أو واجهة إعدادات الخطوط/المسافات الحالية، ولا AI Tailor أو محرر نص غني جديد.
تحذيرات حجم حزمة PDF وeval السابقة ما زالت موجودة، والبناء ينجح. الاختبارات محلية على Linux Chromium؛ لم يُنفّذ PowerShell على Windows هنا.
