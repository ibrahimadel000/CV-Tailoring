# المرحلة الأولى — Batch 10

تحديث محدود يتطلب Batch 09، وليس مشروعاً بديلاً. يعدّل سبعة ملفات ويضيف useEditorAnchor.ts، دون تغيير package.json أو التبعيات أو .env أو خدمات AI أو مصيّر PDF.

## ما تحسّن
1. تصميم مستقل لكل سيرة: اللون، القالب، الخط، حجم النص، وتباعد السطور محفوظة داخل السيرة نفسها. التبديل يعيد تصميم السيرة المختارة؛ نسخ السيرة ينسخ تصميمها بصورة مستقلة. السيرة الجديدة/التجريبية تبدأ بالإعدادات الافتراضية الزرقاء.
2. مسح المسمّى المهني يبقى مسحاً، في الخانة والمعاينة وPDF وبعد إعادة التحميل. البيانات القديمة التي لم تحتوِ خانة desiredJobPosition تستعمل headline القديم؛ لا نخلط غياب الخانة بقيمة فارغة صريحة. زر إظهار العنوان يبقى مستقلاً.
3. فتح/إغلاق قسم أو التبديل بين عناصره يحافظ على ظهور العنوان الذي ضغطه المستخدم بعد انكماش النموذج السابق. Done يعيد التركيز إلى بطاقة العنصر، ويظهرها إذا كانت أعلى المساحة المرئية. التمرير داخل المحرر فقط، وليس الصفحة كلها أو المعاينة.
4. إصلاح حركة البطاقات عند إضافة قسم: لا رسوم انتقال مبنية على مواضع قديمة. حركة الأقسام المجاورة تُحسب مباشرة قبل إعادة الترتيب الفعلية، مع احتساب تمرير المحرر. السحب ما زال يحرك نفس البطاقة ونفس النموذج المفتوح، بالماوس واللمس ولوحة المفاتيح.

## البيانات القديمة والحفظ
- لا حذف للمحتوى أو السير أو الحفظ الداخلي، ولا عودة لتنزيل/استيراد JSON. تنزيل المستخدم يبقى PDF.
- النسخ السابقة كانت تحفظ تصميماً مشتركاً واحداً. عند أول تحميل بعد التحديث يُنسخ ذلك التصميم إلى السير القديمة، ثم يصبح مستقلاً لكل منها. لا يمكن استعادة تصميم تاريخي منفصل لم يكن محفوظاً أصلاً.
- المخطط الجديد اختياري للتوافق مع السير القديمة. تُرفض بيانات السيرة/التصميم غير الصالحة برسالة التحميل الحالية، دون استبدال السجل الذي فشل تحميله.
- الحفظ في نفس المتصفح وعنوان التشغيل/المنفذ، وليس حساباً سحابياً. مسح بيانات المتصفح قد يمسح السير. المثبت يحفظ ملفات المصدر التي يعدّلها، وليس نسخة احتياطية من بيانات العميل.

## التثبيت — كود واحد
أوقف خادم التطوير بـ Ctrl+C، وضع CV-Builder-Foundation-Batch-10.zip داخل E:\cv tailor - Copy دون فكّه يدوياً، ثم الصق:

```powershell
$ErrorActionPreference = "Stop"
$project = "E:\cv tailor - Copy"
$zip = Join-Path $project "CV-Builder-Foundation-Batch-10.zip"
if (-not (Test-Path -LiteralPath $zip -PathType Leaf)) { throw "ZIP not found in the project folder." }
Set-Location -LiteralPath $project
$folder = Join-Path $project ("_cv-foundation-batch10-" + [guid]::NewGuid().ToString("N"))
Expand-Archive -LiteralPath $zip -DestinationPath $folder
& powershell.exe -NoProfile -ExecutionPolicy Bypass -File (Join-Path $folder "Apply-UI.ps1") -ProjectPath $project
if ($LASTEXITCODE -ne 0) { throw "Update stopped. Send the error; do not overwrite files manually." }
npm run build
if ($LASTEXITCODE -ne 0) { throw "Build failed. Send the error." }
npm run dev
```

المتوقع Applied 8 files successfully، أو أن التحديث مطبّق مسبقاً. يفحص المثبت البصمات قبل الكتابة ويضع النسخ الأصلية داخل .cv-builder-backups. عند اختلاف الملفات أو package.json توقف وأرسل الخطأ؛ لا تفرض الاستبدال ولا تنسخ الملفات يدوياً. لا يلزم npm install.
