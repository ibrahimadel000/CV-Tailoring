# CV Builder — UI Batch 02

تحديث لمشروعك الحالي بعد تثبيت Batch 01، وليس مشروعًا مستقلًا.

## الجديد

- دمج البارين العلويين في شريط واحد بارتفاع 60px على الكمبيوتر.
- تقليل عرض التنقّل والمحرر لزيادة المساحة المتاحة للمعاينة.
- ألوان كحلية ورمادية هادئة بدل الخلفية البيضاء على كل مساحة العمل. الورقة نفسها تبقى بيضاء.
- Collapse editor: طيّ المحرر لزيادة مساحة المعاينة.
- Focus preview: إخفاء التنقّل والمحرر مؤقتًا للتركيز على السيرة.
- Follow edit: المعاينة تنتقل تلقائيًا إلى القسم الذي تختاره للتحرير. يمكن تعطيله.
- Fit width للقراءة، وOverview لنظرة عامة على المستند. النص في Overview يكون أصغر بطبيعته.
- Add custom section: إضافة قسم بعنوان من اختيارك وفقرات متعددة، وتعديل عنوانه وفقراته.
- Arrange sections: تحريك الأقسام لأعلى وأسفل. انقر اسم القسم للانتقال إلى تحريره. البيانات الشخصية تبقى أولًا.
- ترتيب الفقرات داخل القسم المخصّص وحذفها بعد التأكيد.
- حفظ الأقسام المخصّصة وترتيب الأقسام في كل سيرة، وتضمينهما في JSON وPDF.
- إزالة المسافات الزخرفية من عناوين PDF لتحسين استخراج النص.

## التطبيق على جهازك

1. قبل إيقاف التطبيق، نزّل JSON backup لسيرتك الحالية، وانتظر رسالة الحفظ.
2. أوقف `npm run dev` باستخدام Ctrl + C.
3. ضع `CV-Builder-UI-Batch-02.zip` داخل `E:\cv tailor - Copy`.
4. افتح PowerShell داخل المشروع وشغّل:

```powershell
Set-Location -LiteralPath "E:\cv tailor - Copy"
$projectRoot = (Get-Location).Path
$updateFolder = Join-Path $projectRoot ("_cv-ui-batch02-" + (Get-Date -Format "yyyyMMdd-HHmmss"))
Expand-Archive -LiteralPath (Join-Path $projectRoot "CV-Builder-UI-Batch-02.zip") -DestinationPath $updateFolder
& (Join-Path $updateFolder "Apply-UI.ps1") -ProjectPath $projectRoot -WhatIf
```

إذا نجح الفحص، وفي نفس نافذة PowerShell:

```powershell
& (Join-Path $updateFolder "Apply-UI.ps1") -ProjectPath $projectRoot
npm run build
npm run dev
```

لا تنسخ `payload` يدويًا. السكربت يتحقق من كل الملفات قبل التغيير ويحتفظ بنسخة احتياطية. إذا ظهرت رسالة Local changes detected، توقف وأرسلها؛ لا تتجاوز الفحص.

## جرب بعد التشغيل

- اختر Skills أو Education وتأكد أن المعاينة تُظهر القسم تلقائيًا.
- جرّب طيّ المحرر ووضع Focus preview والعودة منهما.
- من Add custom section، سمِّ القسم وأضف فقرة أو أكثر.
- من Arrange sections، حرّك القسم الجديد أو الأقسام الأساسية باستخدام الأسهم.
- غيّر ترتيب فقرات القسم المخصّص باستخدام أسهمها.
- انتظر رسالة الحفظ ثم حدّث الصفحة وتأكد أن المحتوى والترتيب محفوظان.
- افتح PDF preview وصدّر PDF للتأكد من الترتيب والمحتوى.
- نزّل JSON backup وأعد استيراده. استيراد النسخ السابقة من Batch 01 ما زال مدعومًا.

## التراجع

سكربت التطبيق يطبع مسار نسخة احتياطية داخل `.cv-builder-backups` في المشروع. استخدمه في:

```powershell
& (Join-Path $updateFolder "Rollback-UI.ps1") -BackupPath "E:\cv tailor - Copy\.cv-builder-backups\BACKUP_FOLDER_NAME"
```

التراجع يعيد كود Batch 01 فقط، ولا يمس بيانات المتصفح. الأقسام الجديدة لا تظهر في واجهة Batch 01؛ لا تستورد نسختها الاحتياطية داخل الإصدار القديم إذا أردت الحفاظ على هذه الإضافات. احتفظ بـJSON صادر من Batch 02.

## حدود النسخة

- لا تغييرات على AI Tailor ولا استدعاءات AI في المسار الجديد.
- العربية/RTL في PDF ما زالت غير مدعومة. لا تغييرات في حدود الخطوط عن Batch 01.
- المعاينة الجانبية مستمرة؛ PDF preview يعرض فواصل الصفحات النهائية.
- ترتيب الأقسام ومحتواها خاص بكل سيرة؛ إعدادات التصميم ما زالت مشتركة بين السير في مساحة العمل.
- الحفظ محلي في المتصفح. استخدم نفس المتصفح والعنوان والمنفذ، واحتفظ بنسخ JSON.
- سيرة طويلة ستحتاج تمريرًا عند قراءتها بحجم كبير؛ Follow edit يقلل التمرير اليدوي إلى القسم الحالي، وOverview يعطي نظرة على الشكل العام.
- سكربتا PowerShell لم يُشغَّلا على Windows في بيئة الاختبار. ابدأ بـ-WhatIf واحتفظ بنسخة المشروع.
