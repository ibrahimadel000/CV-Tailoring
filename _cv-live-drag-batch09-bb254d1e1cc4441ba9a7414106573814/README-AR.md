# تحديث 09 — سحب البطاقة الفعلية وتنزيل PDF فقط

تحديث محدود للمشروع الحالي، يتطلب تثبيت Batch 08. ليس مشروعاً بديلاً.

## ما تغيّر
- سحب الأقسام من مقبض النقاط يحرك بطاقة القسم نفسها، وليس شارة صغيرة باسمها ولا صورة منسوخة عنها.
- ترتفع البطاقة بظل خفيف، ويتحرك موضع فارغ بنفس ارتفاعها وعرضها إلى مكان الإفلات. الأقسام المجاورة تتحرك بسلاسة لتفسح المكان.
- القسم المفتوح يبقى مفتوحاً، ونموذج الوظيفة المفتوح هو نفس عنصر الواجهة؛ لا إعادة تركيب أو فقدان لحالة تحريره أثناء النقل. البطاقة الطويلة تظل كاملة، ويظهر الجزء الذي يقع داخل مساحة المحرر.
- الحركة تبدأ بعد تجاوز 6px من المقبض؛ الضغط دون سحب لا ينقل القسم. الكتابة وتحديد النص وتمرير النموذج تظل تفاعلات طبيعية خارج المقبض.
- تمرير تلقائي قرب حواف المحرر، وحركة استقرار قصيرة عند الإفلات. الترتيب يحفظ فقط بعد إنهاء النقل الصحيح، لا أثناء المرور فوق الأقسام.
- Escape، أو الإفلات خارج مساحة المحرر، أو إلغاء اللمس، أو تغيير حجم النافذة يلغي النقل دون حفظ الترتيب التجريبي.
- التنقل بلوحة المفاتيح من المقبض باقٍ: أعلى/أسفل، Home وEnd. البيانات الشخصية ثابتة أولاً. احترام reduced motion وبديل حدود forced colors.
- إزالة تنزيل/استيراد JSON من الرأس والمكتبة والشاشة الفارغة ونافذة التصدير. تمت إزالة قائمة ⋯ التي لم تعد تحتوي إجراءات أخرى.
- PDF هو خيار تنزيل المستخدم. لا حذف للسير أو للبيانات الداخلية ولا تغيير للمخطط أو طريقة التخزين. النص أصبح Saved in this browser لتوضيح أن الحفظ محلي وليس سحابياً.
- رسائل الخطأ لم تعد توجّه إلى زر JSON غير موجود؛ خطأ الحفظ يطلب إبقاء التبويب مفتوحاً وإعادة محاولة الحفظ.

## ما لم يتغيّر
- ترتيب البيانات المخزن، حقول السيرة، القوالب، تفضيلات الصفحات، المعاينة/التصدير من نفس PDF، وإمكانية متابعة التعديل في نفس المتصفح.
- لا مزامنة سحابية جديدة. مسح بيانات المتصفح قد يمسح السير. PDF نسخة للتقديم وليس ملفاً لإعادة تحميله داخل المحرر.
- لا تغيير لقواعد فتح الأقسام والعناصر، فقط الحفاظ على حالتها أثناء السحب. لا سحب جديد لترتيب الوظائف داخل القسم في هذه الدفعة.
- لا تغيير package.json أو التبعيات أو .env أو خدمات الذكاء الاصطناعي. قيود تصدير العربية السابقة ما زالت كما هي.

## التثبيت — كود واحد
1. أوقف خادم التطوير بـ Ctrl+C.
2. ضع CV-Builder-Live-Drag-Batch-09.zip داخل E:\cv tailor - Copy دون فكّه يدوياً.
3. الصق الكود:

```powershell
$ErrorActionPreference = "Stop"
$project = "E:\cv tailor - Copy"
$zip = Join-Path $project "CV-Builder-Live-Drag-Batch-09.zip"
if (-not (Test-Path -LiteralPath $zip -PathType Leaf)) { throw "ZIP not found in the project folder." }
Set-Location -LiteralPath $project
$folder = Join-Path $project ("_cv-live-drag-batch09-" + [guid]::NewGuid().ToString("N"))
Expand-Archive -LiteralPath $zip -DestinationPath $folder
& powershell.exe -NoProfile -ExecutionPolicy Bypass -File (Join-Path $folder "Apply-UI.ps1") -ProjectPath $project
if ($LASTEXITCODE -ne 0) { throw "Update stopped. Send the error; do not overwrite files manually." }
npm run build
if ($LASTEXITCODE -ne 0) { throw "Build failed. Send the error." }
npm run dev
```

التحديث يفحص بصمات الملفات قبل تعديلها ويحفظ نسخة من **ملفات المصدر التي يعدّلها** داخل .cv-builder-backups. هذا ليس تصدير JSON لبيانات العميل.
المتوقع Applied 5 files successfully أو Already applied إذا سبق تطبيقها. عند اختلاف الملفات أو package.json، توقف وأرسل الخطأ؛ لا تفرض الاستبدال ولا تنسخ الملفات يدوياً. لا يلزم npm install.
افتح التطبيق بنفس المتصفح وعنوان التشغيل/المنفذ السابق للوصول إلى السير المحلية. ملفات البيانات ليست ضمن الحزمة ولا تُمسح أو تُنقل.

## التراجع
يعرض المثبت مسار مجلد النسخة الاحتياطية. للتراجع، شغّل Rollback-UI.ps1 الموجود داخل ذلك المجلد مع -ProjectPath لمسار المشروع. يفحص أن الملفات لم تُعدّل بعد التحديث قبل استعادتها.
