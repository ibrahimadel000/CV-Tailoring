# CV Builder — UI Batch 01

هذه حزمة تغييرات فقط، وليست نسخة بديلة من المشروع كله.
الاسم البصري المؤقت: **folio.** اسم الحزمة البرمجية يبقى `cv-tailor-studio`.

## قبل التطبيق

1. احتفظ بنسخة من مشروعك. انسخ أي بيانات غير محفوظة من التطبيق القديم قبل إغلاقه.
2. أغلق خادم Vite قبل التطبيق.
3. فك ضغط الحزمة في مجلد مستقل، خارج `src`. لا تنسخ مجلد `payload` عشوائيًا فوق مشروعك.
4. الحزمة مطابقة للنسخة التي رفعتها. إذا عدّلت الملفات بعدها، سيوقف سكربت التطبيق العملية بدل الكتابة فوق تعديلاتك.

## التطبيق

افتح PowerShell في مجلد الحزمة بعد فك الضغط، واستبدل مسار المثال بمسار مشروعك الفعلي:

```powershell
.\Apply-UI.ps1 -ProjectPath "C:\path\to\cv tailor - Copy"
```

للفحص دون تطبيق:

```powershell
.\Apply-UI.ps1 -ProjectPath "C:\path\to\cv tailor - Copy" -WhatIf
```

السكربت يتحقق من بصمات الملفات، ثم يحفظ الملفات الأصلية في:

`.cv-builder-backups\<اسم النسخة الاحتياطية>` داخل مشروعك.

إذا رفض Windows تشغيل ملف محمّل، راجع الملف أولًا ثم استخدم خصائص الملف > Unblock إذا ظهر الخيار. لا تحتاج تغيير سياسة تنفيذ PowerShell على الجهاز كله. إذا استمر الرفض، أرسل رسالة الخطأ بدل تغيير إعدادات النظام.

## التشغيل

افتح الطرفية داخل المشروع، ثم:

```powershell
npm run build
npm run dev
```

إذا لم تكن الاعتماديات مثبتة، شغّل `npm ci` أولًا. هذه الدفعة لا تغيّر `package.json` أو `package-lock.json` ولا تضيف اعتماديات.

افتح رابط Vite الذي يظهر. استخدم نفس المتصفح ونفس العنوان والمنفذ للوصول إلى السير المحفوظة سابقًا؛ `localhost` و`127.0.0.1` ليسا نفس مساحة التخزين.

## الاختبار عندك

- أنشئ سيرة جديدة من My resumes > New resume.
- اكتب الاسم والبريد والعنوان الوظيفي. جرّب إخفاء الهاتف أو الموقع.
- أضف ملخصًا، وخبرة، وتعليمًا، ومهارات، ومشروعًا، وشهادة.
- أضف المهارات مفصولة بفواصل، مثل `React, TypeScript`.
- جرّب تحريك مدخلات الخبرة والتعليم والمشروعات والشهادات لأعلى/أسفل.
- انتظر ظهور `All changes saved on this device`، ثم حدّث الصفحة وتأكد من بقاء البيانات.
- غيّر القالب واللون وحجم النص والتباعد من Design.
- افتح PDF preview للتأكد من فواصل الصفحات، ثم صدّر PDF.
- نزّل JSON backup، ثم استورده من My resumes. الاستيراد ينشئ نسخة جديدة ولا يستبدل السيرة الحالية.
- جرّب عرضًا بعرض 390px في أدوات المتصفح أو جرّب هاتفك.

## نطاق هذه الدفعة وحدودها

- واجهة إنجليزية، وبناء يدوي للسيرة. لا استدعاءات AI في مسار البناء الجديد.
- كود AI Tailor القديم بقي موجودًا، لكنه غير موصول بالواجهة الجديدة الآن.
- 3 قوالب نصية بعمود واحد: Essential، Editorial، Compact.
- إعدادات التصميم مشتركة في مساحة العمل في هذه الدفعة؛ ليست إعدادات مستقلة لكل سيرة.
- المعاينة الجانبية مستمرة، وليست محاكاة مطابقة لفواصل الصفحات؛ PDF preview يعرض الملف الفعلي.
- تصدير PDF يدعم الأحرف الأساسية اللاتينية واللكنات الغربية الشائعة. دعم العربية والخطوط والتشكيل واتجاه RTL يحتاج دفعة مستقلة. يمنع التطبيق تصدير أحرف غير مدعومة بدل إنتاج نص ناقص.
- يمكن إدخال بيانات عربية وحفظها وعمل نسخة JSON منها، لكن PDF العربي غير جاهز.
- لا صور شخصية في هذه القوالب النصية. بيانات الصور القديمة لا تُحذف من السيرة.
- الحفظ في IndexedDB داخل المتصفح، وليس سحابيًا. مسح بيانات المتصفح قد يزيل السير؛ احتفظ بنسخ JSON آمنة.
- استيراد ملف CV بصيغة PDF، إضافة المتصفح، حسابات المستخدمين، ومزامنة الأجهزة ليست ضمن هذه الدفعة.
- لا ضمانات لدرجات ATS أو فرص التوظيف. قائمة The essentials قائمة محتوى فقط.

## التراجع

افتح PowerShell داخل مجلد الحزمة، وحدد مجلد النسخة الاحتياطية الذي طبعه سكربت التطبيق:

```powershell
.\Rollback-UI.ps1 -BackupPath "C:\path\to\project\.cv-builder-backups\BACKUP_FOLDER_NAME"
```

سيعيد الملفات الأصلية ويحذف الملفات الجديدة التي أضافتها الدفعة. يتوقف إذا وجد تعديلات أحدث في الملفات حتى لا يمسح عملك. التراجع يعيد الكود فقط، ولا يغيّر بيانات IndexedDB في المتصفح.

## ملاحظة اختبار

اختُبر كود التطبيق محليًا على Linux/Chromium. سكربتا PowerShell تمت مراجعتهما، لكن لم يتم تشغيلهما على Windows في بيئة الاختبار. ابدأ بـ `-WhatIf`، ثم طبّق على نسخة مشروعك واختبرها.
