# تحديث 08 — تجربة إدخال أهدأ وأوضح

تحديث داخل المشروع الحالي، وليس مشروعاً مستقلاً. يتطلب Batch 07 المثبّت بنجاح.

## التصميم
- حقول رمادية خفيفة على خلفية محرر بيضاء، دون إطار صندوقي بارز من جميع الجهات؛ خط سفلي رفيع يوضّح حدود الحقل.
- ارتفاع 52px وخط إدخال 16px، مع لون تركيز واضح عند الكتابة أو التنقل بلوحة المفاتيح.
- بيانات الهوية أولاً، ثم Contact information، ثم Links & extra details. حقول الأسماء والبريد/الهاتف تتجاور عند اتساع المساحة فقط، والموقع يأخذ العرض كاملاً.
- على الهواتف والعمود الضيق تتحول الحقول إلى عمود واحد، دون ضغط الأسماء الطويلة أو خيارات الإظهار.
- مفاتيح Show / Hidden بجانب الحقل نفسه، وUse as headline بجانب العنوان الوظيفي. الإخفاء لا يمسح النص المخزن.
- نفس نمط الإدخال يصل إلى الخبرات والتعليم والمشاريع والشهادات والأقسام المخصصة وخيارات التصميم.

## تحسينات فعلية أثناء الكتابة
- تلميحات تعبئة المتصفح للأسماء والبريد والهاتف والموقع والعنوان الوظيفي، دون اختراع بيانات المستخدم أو ملئها تلقائياً من عندنا.
- تنبيه صيغة البريد يظهر بعد مغادرة الحقل، لا عند كل حرف في بداية الكتابة. مرتبط بالحقل لقارئ الشاشة ويختفي عند التصحيح. ليس حظراً جديداً على الحفظ أو التصدير.
- الروابط والتفاصيل الاختيارية تُضاف عند الحاجة، وينتقل المؤشر إلى الحقل الذي أضفته.
- خانة Role overview الفارغة لا تزاحم الإنجازات؛ اضغط Add role overview لإظهارها. الأوصاف القديمة المعبأة تظهر تلقائياً ولا تُحذف.
- مساحات النص والإنجازات تتمدد مع النص وعند تغير عرض المحرر. التمدد التلقائي يصل إلى 480px؛ النص الأطول يبقى قابلاً للتمرير والتعديل، ولا يُقصّ أو يُختصر. يمكن تغيير ارتفاع مساحة النص يدوياً أيضاً.
- Add achievement ينقل المؤشر إلى النقطة الجديدة. بعد إزالة نقطة ينتقل إلى نقطة مجاورة أو زر الإضافة.
- في الخبرة والأقسام المخصصة ذات التواريخ، تحديد I currently work here / Ongoing يجعل النهاية Present ويوقف تحرير تاريخ النهاية حتى إلغاء الاختيار. التاريخ الذي أدخلته يعود إذا ألغيت الاختيار داخل جلسة تحرير العنصر نفسها؛ لا ندّعي استرجاع تاريخ غير مخزن بعد إغلاق العنصر أو إعادة التحميل.
- Enter يضيف المهارات دون الحاجة للنقر، مع احترام تركيب النص عبر IME. الحقول النصية الطويلة تبقى تستخدم Enter كسطر جديد.
- مساحات نقر مناسبة، تركيز لوحة مفاتيح واضح، واحترام reduced motion وبديل للمفاتيح في forced colors.

## ما لم يتغير
البيانات وشكل JSON والمخزن وملفات PDF وقواعد الصفحات في Batch 07 والتبعيات و.env وخدمات AI لم تُعدّل. لم نضف العمر أو الحالة الاجتماعية أو الجنس أو رفع صورة، ولم ننقل كل حقول الموقع المرجعي بلا حاجة.
قيود تصدير العربية السابقة ما زالت كما هي. لا AI Tailor جديد، ولا منتقي تواريخ جديد؛ التواريخ تبقى نصية.

## التثبيت — كود واحد
1. نزّل Download JSON backup من قائمة ⋯ واحتفظ به.
2. أوقف خادم التطوير بـ Ctrl+C.
3. ضع CV-Builder-Input-UX-Batch-08.zip داخل E:\cv tailor - Copy دون فكّه يدوياً.
4. الصق هذا الكود في PowerShell:

```powershell
$ErrorActionPreference = "Stop"
$project = "E:\cv tailor - Copy"
$zip = Join-Path $project "CV-Builder-Input-UX-Batch-08.zip"
if (-not (Test-Path -LiteralPath $zip -PathType Leaf)) { throw "ZIP not found in the project folder." }
Set-Location -LiteralPath $project
$folder = Join-Path $project ("_cv-input-ux-batch08-" + [guid]::NewGuid().ToString("N"))
Expand-Archive -LiteralPath $zip -DestinationPath $folder
& powershell.exe -NoProfile -ExecutionPolicy Bypass -File (Join-Path $folder "Apply-UI.ps1") -ProjectPath $project
if ($LASTEXITCODE -ne 0) { throw "Update stopped. Send the error; do not overwrite files manually." }
npm run build
if ($LASTEXITCODE -ne 0) { throw "Build failed. Send the error." }
npm run dev
```

المتوقع Applied 4 files successfully (أو أقل إذا كانت مطبّقة سابقاً). إذا ظهر Local changes detected أو اختلاف package.json، أرسل الخطأ ولا تفرض الاستبدال. لا يلزم npm install.
افتح التطبيق بنفس المتصفح وعنوان التشغيل/المنفذ السابق للوصول إلى السير المحلية.

## الحماية والتراجع
أربعة ملفات موجودة معدّلة فقط. المثبّت يتحقق من كل البصمات قبل الكتابة ويحفظ الأصل داخل .cv-builder-backups ويطبع المسار. Rollback-UI.ps1 داخل النسخة الاحتياطية يدعم التراجع باستخدام -BackupPath ويتوقف عند وجود تغييرات لاحقة.
لم يتم مسح بيانات المتصفح أو تعديل السير أثناء التثبيت. حافظ على نسخ JSON المهمة.

البناء والاختبارات نجحت محلياً على Linux Chromium. لم يُنفّذ PowerShell على Windows هنا، ولا ندعي تدقيق وصول شامل أو اختبار أجهزة فعلية ومتصفحات متعددة. تحذيرات حجم حزمة PDF وeval السابقة ما زالت موجودة والبناء ينجح.
